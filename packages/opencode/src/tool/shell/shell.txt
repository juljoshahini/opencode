IMPORTANT: This tool is reserved for filesystem operations that have no dedicated tool — primarily `mv` (rename/move) and `cp` (copy). DO NOT use it for:
- File operations that already have dedicated tools — use those tools instead:
  - Read files → use the Read tool (NOT cat/head/tail/Get-Content)
  - Write/create files → use the Write tool (NOT echo/Set-Content/Out-File)
  - Edit files in place → use the Edit tool (NOT sed/awk)
  - Delete files → use the Delete tool (NOT rm/Remove-Item)
  - Find files → use the Glob tool (NOT find/Get-ChildItem)
  - Search file contents → use the Grep tool (NOT grep/rg/Select-String)
- Running scripts or executing programs — this environment has no Python, Node, package managers, docker, git, or any other runtime, and is not intended for code execution.
- Network requests — use the webfetch or url_screenshot tools instead.
- Communication — output text directly in your response rather than `echo` / `Write-Output` / `Write-Host`.
